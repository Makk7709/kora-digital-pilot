# git filter-repo --replace-text patterns
#
# Usage (depuis le repo principal /Users/aminemohamed/Desktop/APP/kora,
# APRES rotation des clés et création du tag pre-filter-repo) :
#
#     git filter-repo --replace-text scripts/filter-repo-patterns.txt --force
#
# Format documenté ici :
#   https://htmlpreview.github.io/?https://github.com/newren/git-filter-repo/blob/docs/html/git-filter-repo.html#_replace_text
#
# Chaque ligne est soit :
#   - une chaîne littérale "FOO==>REPLACEMENT"
#   - un préfixe "literal:" / "regex:" / "glob:" pour forcer le type
# Les lignes commençant par # sont ignorées.
#
# Nous remplaçons par [REDACTED-<type>] pour que les diffs restent lisibles
# tout en ne ré-injectant aucun secret valide.

# === API keys (les chaînes ci-dessous attrapent la clé complète) ===
