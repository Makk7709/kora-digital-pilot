## 🚀 **Comment Utiliser les Actions IA**

### **Étape 1 : Accéder au Planning**
1. Ouvrez l'application Kora Digital
2. Cliquez sur l'onglet **"Planning Éditorial"**
3. Vous verrez les **Actions IA Rapides** dans la colonne de droite

### **Étape 2 : Utiliser une Action**
1. **Choisissez** l'action souhaitée
2. **Cliquez** sur le bouton correspondant
3. **Attendez** 1-2 secondes (mode simulation)
4. **Vérifiez** le contenu généré dans votre planning

### **Étape 3 : Personnaliser le Contenu**
1. **Cliquez** sur le post généré
2. **Modifiez** le contenu selon vos besoins
3. **Ajustez** l'horaire de publication
4. **Sauvegardez** vos modifications

## ⚙️ **Configuration Avancée (Optionnelle)**

### **Activer le Mode Perplexity Réel**

Si vous souhaitez utiliser de vraies données temps réel :

1. **Obtenez une clé API Perplexity** :
 - Rendez-vous sur [perplexity.ai](https://perplexity.ai)
 - Créez un compte développeur
 - Générez votre clé API

2. **Configurez l'environnement** :
 ```bash
 # Créez un fichier .env à la racine du projet
 VITE_PERPLEXITY_API_KEY=votre_vraie_cle_api_ici
 VITE_PERPLEXITY_MODEL=sonar-pro
 VITE_PERPLEXITY_MAX_TOKENS=4000
 ```

3. **Redémarrez l'application** :
 ```bash
 npm run dev
 ```

4. **Vérifiez le statut** :
 - Le statut passera de "Mode Simulation" à "Perplexity Connecté"
 - Le badge "Démo" disparaîtra

## 🔍 **Dépannage**

### **Les Actions ne Fonctionnent Pas**
1. ✅ Vérifiez que le point est vert
2. ✅ Vérifiez la présence du badge "Actif"
3. ✅ Rechargez la page (F5)
4. ✅ Vérifiez la console développeur (F12)

### **Mode Simulation Bloqué**
1. ✅ Vérifiez votre clé API Perplexity
2. ✅ Vérifiez le fichier .env
3. ✅ Redémarrez le serveur de développement

### **Contenu Non Généré**
1. ✅ Attendez la fin du chargement
2. ✅ Vérifiez les notifications toast
3. ✅ Consultez l'onglet Planning pour voir les nouveaux posts
