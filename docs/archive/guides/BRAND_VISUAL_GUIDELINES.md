### ✅ Checklist Premium
```
Éléments Obligatoires:
□ "ultra-realistic photography"

□ "natural lighting" ou équivalent
□ "premium" ou "sophisticated"
□ Environnement spécifique défini
□ Atmosphère de marque incluse

Éléments Recommandés:
□ "ultra-high resolution"
□ "professional" dans la description
□ Objectif photo spécifié
□ Composition définie
□ Style cohérent avec l'identité Kora
```

### ❌ Éléments à Éviter
```
Interdits:
- Prompts génériques sans spécifications
- Références à des marques concurrentes
- Styles incohérents avec l'identité
- Qualité inférieure à HD
- Éclairage artificiel sans justification

Déconseillés:
- Prompts trop courts (<50 caractères)
- Absence d'atmosphère définie
- Équipement non spécifié
- Environnements vagues
```
